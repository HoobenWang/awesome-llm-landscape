# Contributing ・ 贡献指南

**English**

This list moves fast and is only useful if it stays accurate. PRs welcome for:

- Adding a model/organization that's missing.
- Fixing an outdated version number or dead link.
- Correcting a logo/favicon that doesn't load.
- Translating or improving the Chinese (`README.zh-CN.md`) or English (`README.md`) copy — please keep both files in sync.

When adding an entry, please include: organization, model family, one-line description of what it's known for, and an official link. Keep the mind map diagrams high-level — put detail in the tables, not the diagram.

---

**简体中文**

这份清单更新很快，只有保持准确才有意义。欢迎通过 PR：

- 补充遗漏的模型或机构。
- 修正过时的版本号或失效链接。
- 修复无法加载的 Logo/favicon。
- 翻译或完善中文（`README.zh-CN.md`）或英文（`README.md`）内容——请保持两个文件同步更新。

新增条目时，请附上：所属机构、模型家族、一句话介绍其擅长领域，以及官方链接。思维导图请保持在高层级概览，细节放进表格里，不要堆进图里。
